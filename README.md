# Convee Education

Unified digital campus collaboration platform for schools, colleges, and educational institutions.

## 📂 Project Structure

- **`/backend`**: Node.js + Express + Prisma (PostgreSQL) REST & WebSocket API.
- **`/frontend`**: React web dashboard (Faculty, Student & Parent portals).
- **`/mobile`**: React Native (Expo SDK 52) cross-platform mobile app for Android and iOS.
